# Import

Die Importseite erlaubt es, bestehende Tourdaten in das Plugin zu übernehmen.

## Menü

**Trombongos Tour → Import**

## Vorgehen

1. Vor dem Import sicherstellen, dass eine [Saison](seasons.md) existiert, in die die
   Daten importiert werden sollen.
2. Die Importseite im Backend öffnen und den dortigen Anweisungen folgen.

!!! warning "Datenbank sichern"
    Vor grösseren Importvorgängen empfiehlt es sich, ein Backup der Datenbank zu
    erstellen. Die Migrationsskripte im Verzeichnis `db_migration/` dokumentieren
    Änderungen am Datenbankschema (siehe [Datenbank](../database.md)).
