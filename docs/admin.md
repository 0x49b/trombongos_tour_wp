# Admin

After activation, a **Trombongos Tour** menu appears in the WordPress admin sidebar.

| Screen | Purpose |
|--------|---------|
| Übersicht | Overview of tour data |
| Auftritte | Create and edit events |
| Kategorien | Manage categories linked to a season |
| Saisons | Manage seasons and set the active season |
| Transport | Manage transport options (including a default) |
| Import | Import tour data |

Only users with the `manage_options` capability can access these screens.
